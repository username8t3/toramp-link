# Toramp Link

Неофициальный плагин Lampa для списка сериалов Toramp и синхронизации просмотренных серий. Работает напрямую с Toramp: собственный сервер, телефон с Termux и код сопряжения не нужны.

**Статус: 0.5.0-beta.1, экспериментальная сборка.** В установленной Tizen Lampa пользователь подтвердил восстановление cookie-сессии и загрузку списка в полной сборке. Настоящая смена статуса, отметка серии и работа при выключенном прежнем сервере ещё требуют проверки. Прямой вход с паролем был проверен предыдущим прототипом. Автотесты используют вымышленные данные и не подтверждают работу на телевизоре.

## Возможности

- «Продолжить» — следующая вышедшая непросмотренная серия, с учётом незавершённого просмотра в Lampa.
- «Непросмотренные серии» — включая старые пропущенные эпизоды.
- Категории «Смотрю», «Посмотрел», «Хочу посмотреть», «Отложено», «Брошено».
- Ручная смена статуса, автоматическое добавление в «Смотрю» после начала просмотра.
- Обмен просмотренными отметками. Порог Lampa — 95%; плагин не снимает существующие отметки.
- Устойчивая очередь: HTTP 200 не считается подтверждением; плагин повторно читает результат в Toramp.
- При повторном просмотре сериал переводится из «Посмотрел» в «Смотрю».

Сопоставление серий требует совпадения сезона, номера и даты выхода. Спецвыпуски автоматически не связываются. Неоднозначное название требует выбора пользователя; фоновая работа не выбирает сериал наугад.

## Установка

Экспериментальная сборка: [toramp-link.js](https://username8t3.github.io/toramp-link/toramp-link.js).

Добавьте в расширения Lampa этот адрес:

```text
https://username8t3.github.io/toramp-link/toramp-link.js
```

Это beta-версия, а не стабильный выпуск. Перед установкой учитывайте перечисленные выше непроверенные сценарии.

Lampa запускает только готовый `toramp-link.js`: один JavaScript-бандл, который собирается GitHub Actions и размещается на GitHub Pages. Пользователю не нужны исходники TypeScript, Node.js или самостоятельная сборка. Этот репозиторий содержит исходники для разработчиков; приватные серверные инструменты в сборку не входят.

Для тестовой установки:

1. Отключите старый плагин Toramp через локальный сервер. Две версии одновременно включать нельзя.
2. В настройках расширений Lampa добавьте HTTPS-адрес выше. Если уже установлена временная сборка Toramp Link с другого адреса, замените её; одновременно две копии включать нельзя.
3. Полностью перезапустите Lampa.
4. Откройте **Настройки → Toramp Link → Войти в Toramp**.
5. Если cookie-сессия на устройстве уже активна, плагин проверит её без повторного ввода пароля. Иначе введите логин и пароль клавиатурой Lampa.
6. Откройте **Toramp Link** в левом меню.

**Настройки → Toramp Link → Аккаунт и синхронизация** показывает аккаунт, очередь, последнюю синхронизацию и ошибку; там же доступны проверка подключения и выход.

Один аккаунт Toramp используется всеми профилями Lampa на устройстве. Очереди, категории, кэш и связи сериалов разделены по аккаунту Toramp и профилю Lampa. При смене аккаунта чужая очередь не отправляется.

## Совместимость и ограничения

Прямой доступ зависит от политики установленной Lampa. Обычная браузерная Lampa может блокировать запросы или доступ к cookie; плагин не обходит эту политику. Поддержка Android, webOS и других вариантов Tizen пока не заявлена.

Сборка преобразует синтаксис для Chromium 56. Это техническая цель сборки, а не обещание поддержки всех телевизоров с таким движком. Среда должна предоставлять `Promise`, `URL`, `DOMParser`, `XMLHttpRequest`, `localStorage` и используемые методы Lampa.

Используется внутренний протокол сайта Toramp, не официальный публичный API. Изменения сайта могут потребовать обновления. Фильмы и удаление сериалов из списка не реализованы.

Связи старого серверного плагина не переносятся автоматически: новый плагин проверяет соответствие заново. Старые данные не удаляются. Не очищайте данные приложения Lampa, если хотите сохранить локальные очереди и cookie-сессию.

## Приватность

Исходники этого плагина, тесты на вымышленных данных и сборка открыты. Прежний серверный плагин снят с разработки; его локальный архив и экспериментальные прототипы не входят в этот репозиторий и не требуются для установки. Пароли, cookie, токены и реальные списки аккаунта не должны храниться в Git.

Пароль отправляется только в HTTPS-запросе Toramp; плагин не записывает его в хранилище. Сессией управляет установленная Lampa. Плагин не экспортирует cookie и CSRF-токен, не отправляет собственную телеметрию и не содержит адреса домашнего сервера.

Локально сохраняются связи сериалов, кэш и ожидающие отметки. «Выйти» завершает сессию Toramp на устройстве, а локальная очередь остаётся связанной с прежним аккаунтом. Сохранение входа зависит от cookie-политики приложения и срока сессии Toramp.

## Разработка

Требуется Node.js 24 и npm. Node.js нужен разработчику, не телевизору.

```sh
npm ci
npm run check
```

Результат сборки — `dist/toramp-link.js`, один IIFE-скрипт без внешних импортов.

В `src/client.ts` находится протокол Toramp, в `parser.ts` — проверка HTML, в `gateway.ts` — хранение связей и изоляция аккаунтов. `src/lampa.js` сохраняет проверенные сценарии штатного интерфейса Lampa; это JavaScript, а сетевые и предметные модули написаны на TypeScript.

`tests` проверяет синтетический протокол и собранный файл. Порядок подготовки выпуска: [RELEASE-CHECKLIST.md](RELEASE-CHECKLIST.md). Правила участия: [CONTRIBUTING.md](CONTRIBUTING.md).
