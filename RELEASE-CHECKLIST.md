# Подготовка публичного выпуска

## Локальная проверка

- [x] Собирается один скрипт без внешних модульных импортов.
- [x] Нет LAN-адреса, bearer-ключа и отправки диагностики.
- [x] Очередь разделена по аккаунту Toramp и профилю Lampa.
- [x] Синтетические тесты проверяют реальные изменения статуса и серии с повторным чтением, неподтверждённую запись, сбои и смену профиля.
- [x] Собранный скрипт проверен в тестовой среде DOM/Lampa.
- [x] Проверена текущая разметка пяти категорий Toramp через серверную сессию: аккаунт в глобальном меню и отдельный блок пустого списка. Эти случаи покрыты регрессионными тестами; проверка не доказывает работу новой сборки на телевизоре.
- [x] Текущая сборка просмотрена в настоящем браузерном Lampa runtime на вымышленных данных: список, непросмотренные серии, переход пультом во второй ряд и пустая категория.

## Проверка на установленной Tizen Lampa

Результаты предыдущего прототипа не закрывают пункты новой полной сборки.

- [x] Восстановление уже активной cookie-сессии: пользователь подтвердил загрузку списка после перезапуска исправленной полной сборки. Новый вход в этой сборке отдельно не проверен.
- [ ] Все категории, включая пустую; «Продолжить» и «Непросмотренные серии».
- [ ] Пульт: карточки, вкладки в нескольких рядах, возврат из диалогов.
- [ ] Выбранный пользователем статус изменён и подтверждён в Toramp.
- [ ] Выбранная пользователем серия отмечена и подтверждена в Toramp.
- [ ] Обратный импорт просмотренной отметки в Lampa.
- [ ] Отключён прежний сервер: список, статус и серия работают напрямую.
- [ ] Полный перезапуск Lampa: вход и ожидающие отметки сохраняются.
- [ ] Выход и повторный вход не отправляют очередь другого аккаунта.
- [ ] Автоматическое добавление после начала просмотра и повторный просмотр.

## Публичная публикация

- [ ] Зафиксировать платформы, действительно прошедшие проверку.
- [ ] Создать отдельный репозиторий только из этой папки; не публиковать соседние research, сервер и личные данные.
- [ ] Проверить CI на GitHub.
- [ ] Включить Pages с источником GitHub Actions; выполнить ручной workflow Publish.
- [ ] Проверить HTTPS-адрес файла, MIME-тип и побайтовое соответствие сборке.
- [ ] Загрузить этот адрес в Lampa и повторить основной сценарий.
- [ ] Обновить README реальной ссылкой и доказанным статусом; создать версионный Release.

Публикация до закрытия телевизионных пунктов допустима только как явно экспериментальная тестовая сборка, с перечислением непроверенных сценариев.
