# Участие в разработке

Перед изменениями выполните `npm ci` и `npm run check`. В описании изменений укажите проблему, новое поведение, выполненные проверки и ограничения.

Публичный репозиторий содержит только самостоятельный плагин, вымышленные тестовые данные, документацию и сборку. Прежний сервер снят с разработки; не переносите его локальный архив, прототипы или личные инструменты в этот репозиторий. `.gitignore` ограничивает добавление файлов, а `npm run check` проверяет явный список отслеживаемых путей. Для нового публичного файла обновите этот список после проверки содержимого.

Для сетевых и синхронизационных изменений добавляйте проверки на отказ: гостевой ответ с HTTP 200, неподтверждённая запись, смена аккаунта или профиля во время запроса, восстановление очереди после перезапуска. Вымышленные данные обязательны: не добавляйте cookie, пароли, токены и личные списки в репозиторий, логи или issue.

Для интерфейса используйте компоненты, тему, клавиатуру и управление фокусом Lampa. Название, версия и общая иконка находятся в `src/brand.ts`. Toramp — название интеграции; Toramp Link — название плагина. Не меняйте формат хранилища без явной миграции.

Проверка на телевизоре должна перечислять платформу, версию Lampa, сценарий и результат. Браузерные тесты не являются подтверждением работы на Tizen.
